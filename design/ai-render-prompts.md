# AI 3D Render Prompts

Use the same base style for every object so the set looks consistent. Generate each object as a **separate image** and remove the background (or ask for a transparent background).

## Base style (put this in every prompt)

> Soft 3D render, clay and matte plastic materials with a light gloss, rounded friendly shapes, studio lighting from the top left, soft shadow underneath, slight tilt as if floating, playful brand identity style, isolated on a plain warm cream background (#F2ECE3), centered, no text, no people. Colour palette: lavender #BDB2F5, lime #D4DE3A, warm red #E0352B, gold #F5B83D, maroon #3B0D12 accents only.

## Export

- Size: 1024 × 1024, PNG with transparent background.
- Save to `design/assets/3d/` with the file names above.
- Run through an image compressor (e.g. squoosh.app, WebP output) before using them in the app.

## Photos

Free stock from Unsplash or Pexels. Search terms: "call center agent smiling", "customer service desk", "retail staff helping customer", "office team headset". Crop to warm, natural light where possible.
